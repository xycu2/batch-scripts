# ⚡ Batch Scripts Collection

Collection of Batch Scripts (`.bat`) for automation routine tasks development in the environment Windows.

---

## 🚀 Доступные скрипты

### 1. `push.bat` — Авто-пуш в Git

Скрипт создан для того, чтобы не вводить команды `git add`, `git commit` и `git push` вручную по многу раз в процессе активной разработки проекта.

> ⚠️ **Важное примечание:** Перед использованием скрипта ваш репозиторий уже должен быть инициализирован (`git init`), привязан к GitHub и иметь сделанный вручную первый коммит.

#### ✨ Возможности:
- Настройка кодировки UTF-8 (`chcp 65001`) для корректного отображения кириллицы в консоли.
- Использование `@echo off` для чистого вывода сообщений.
- Интерактивный ввод сообщения коммита прямо из терминала.
- Пауза в конце работы, чтобы окно не закрывалось автоматически.

#### 🛠️ Алгоритм работы:
1. Выполняет `git add .` (добавляет все изменения).
2. Запрашивает текст коммита у пользователя.
3. Выполняет `git commit -m "%MSG%"`.
4. Выполняет `git push` на удалённый репозиторий.

#### 💻 Запуск:
В терминале **Git Bash** (в VS Code):
```bash
./push.bat
```
В командной строке **CMD**:
```DOS
push.bat
```

## 2. `openPrograms.bat` — Авто-запуск рабочего окружения

Скрипт создан для того, чтобы не открывать вручную основные программы (VS Code, Chrome, Obsidian) каждый раз перед началом работы.

> ⚠️ **Важное примечание:** Убедитесь, что пути к `.exe` файлам соответствуют стандартным директориям установки в вашей системе Windows.

### 🍱 Возможности:

* Настройка кодировки UTF-8 (`chcp 65001`) для корректного отображения кириллицы в консоли.
* Использование `@echo off` для чистого вывода сообщений.
* Проверка наличия программ по указанным путям перед запуском.
* Безопасный запуск приложения без остановки работы скрипта при отсутствии софта.

### 🛠️ Алгоритм работы:

1. Проверяет наличие **VS Code** и запускает его при обнаружении.
2. Проверяет наличие **Google Chrome** и открывает браузер.
3. Проверяет наличие **Obsidian** и запускает приложение для заметок.
4. Выводит итоговый статус `[✓] Всё успешно запущено!` и завершает работу.

### 💻 Запуск:

В терминале **Git Bash** (в VS Code):

```bash
./openPrograms.bat
```

В командной строке **CMD**:

```DOS
openPrograms.bat
```

#### 📌 Заметки
Скрипты оптимизирован для работы как в стандартной командной строке Windows, так и в терминале VS Code.
